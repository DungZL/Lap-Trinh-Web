# Lap-Trinh-Web - KiddoZone

Website bán đồ chơi trẻ em (đồ án môn Lập trình Web): PHP 8 thuần + MySQL/MariaDB (PDO), Bootstrap 5, JavaScript thuần, TinyMCE. Chạy trên **XAMPP** hoặc **Laragon**, hỗ trợ deploy lên **InfinityFree / Render**.
